# Projects

这里保存一至三个周末能够完成的阶段性学习项目。它们比单个练习完整，但不包含
独立的 Song2Piano 个人兴趣项目代码。

每个项目应至少提供：

```text
<project>/
├── README.md       问题、方法和运行方式
├── configs/        可复现实验配置
├── tests/          关键行为测试
├── report.md       指标、图表、错误分析和结论
└── samples/        少量且许可证允许的代表性结果
```

完成标准：陌生人在干净环境中能够运行；结果有量化指标；失败案例被解释；报告明确
说明哪些结论值得迁移到独立的个人兴趣项目。
